# 公文体邮件格式与措辞规范

适用：oa-email 通过通达 OA 内部邮件发送的日常办公邮件（通知、会议、报送、
请示、汇报、回复、通用事项等）。

原则：正式公文体、简洁准确、有据可查、结尾留联系方式。

## 主题格式

`【类型】<事项>（<时间或截止>）`

| 类型 | 主题示例 |
|---|---|
| 通知 | 【通知】关于开展2026年度教学工作业绩考核的通知 |
| 会议 | 【会议通知】11月12日14:00 教务工作例会（行政楼302） |
| 工作提醒 | 【工作提醒】报送2026年度绩效自查表（11月10日前） |
| 材料报送 | 【报送提醒】2026年度实践教学数据（11月15日前） |
| 请示 | 【请示】关于增加考试监考人员的请示 |
| 汇报 | 【汇报】教务处第10周工作完成情况 |
| 回复 | 【回复】关于教学检查安排的反馈 |
| 通用 | 简明短语概括事项（如"教材征订计划提交"） |

用户给的主题口语化/过长/无类型词时规范为上述格式；改动在预览时向用户说明，
用户不同意则按用户原题发送。

## 正文结构（四段式，按类型调整）

```
<称呼>：

<背景/依据>。根据……要求/为……，现将有关事项通知如下：

<事项与要求>：……

<截止时间/注意事项>。
联系人：万志平（教务处）。

<结束语：特此通知。/请遵照执行。/盼复。/此致>

万志平
教务处
2026年11月8日
```

## 各类型必含要素

| 类型 | 必含要素 |
|---|---|
| 通知 | 依据、事项、要求、执行范围、截止/生效时间、联系人 |
| 会议通知 | 会议名称、时间、地点、参会人员、议题/需准备材料 |
| 工作提醒/催办 | 依据、事项、当前要求、截止；催办语气委婉（"请尽快""烦请"） |
| 材料报送 | 依据（通知名称）、材料清单、格式要求、报送方式、截止 |
| 请示 | 事由、背景、请求事项、理由；结尾"妥否，请批示" |
| 汇报 | 已完成工作（要项）、数据、问题、下一步；条目清晰 |
| 回复 | 引原邮件主题、逐点答复、说明对方需要的后续动作 |
| 通用 | 事项说明、要求、截止、联系人 |

## 措辞规范

- 称呼：校内人员用"<姓名>老师："或职务（如"张主任："）；不确定时用"XX老师："；多人用"各位老师："
- 语气：正式、尊重、不命令；催办用"请尽快""烦请"等委婉表达
- 简洁：正文一般 ≤200 字（通知类可放宽）；无关信息不写
- 标点全角；日期写法"11月10日"或"2026年11月10日"
- 依据可附来源链接（门户通知 URL）；**文件名、文号、日期不凭记忆写**，以用户提供为准
- 有附件时正文提一句"详见附件"，并列出附件名

## 完善内容的规则（重要）

用户输入是"主要内容"，完善时：

1. **只动形式与表达**（结构、措辞、标点、称呼、落款、主题规范），**不动事实与要求**
2. 要点式 → 按类型模板扩写；成文 → 只整理润色、修正错别字
3. 用户没给的细节（依据文号、具体时间地点、数据）**不脑补**——用占位符并在预览时问，宁可问不可编
4. 预览时简要说明改动点（如"补了依据句和落款""主题加【通知】""第2点拆成两段"）
5. 称呼不确定、多人排序、抄送对象等涉及人际判断的，预览时列出选项让用户定
