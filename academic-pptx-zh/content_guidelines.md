# 学术演示文稿内容规范（中文版）

## 1. 论证结构

### 开场即亮研究问题
中心问题或主张必须在第 2–3 页内明确陈述。听众需要它来评估后续一切内容，不要把它藏起来。

### 采用成熟的叙事主线（选一种并贯彻到底）

- **方案 A — 情境 / 冲突 / 解决（SCR）**
  - 情境：已知或已确立的事实
  - 冲突：缺失、矛盾、被质疑或未解释的部分
  - 解决：你的工作贡献了什么

- **方案 B — 漏斗 + 答案**
  - 大背景 → 具体缺口 → 你的方法 → 关键发现 → 启示

- **方案 C — 答案先行**（面向资深/时间紧张的听众）
  - 先给结论，再给支撑；适用于课题评审、咨询委员会、短报告

### 一场只讲一个论点
不要试图呈现整篇论文。选择限时内能讲透的那个主张，其余全部进附录。

### 每页一个职责
每页在论证中承担单一明确角色。一页干两件事就拆成两页。

### 流程测试
列完大纲后按顺序读标题：每页应让下一页显得顺理成章。如果某页可以出现在序列中任何位置而不影响理解，它要么放错了地方，要么多余。

---

## 2. 行动标题（最重要的格式规则）

**每页标题必须是陈述结论的完整句子（"so what"），而非主题标签。**

| 主题标签（错误） | 行动标题（正确） |
|------------------|------------------|
| 结果 | 处理效应在全部三个队列中均显著 |
| 文献综述 | 已有研究未能解释因果机制 |
| 数据 | 数据集覆盖 40 年县级面板数据 |
| 研究方法 | 断点回归利用了陡峭的资助门槛 |
| 讨论 | 控制选择与 attrition 后效应依然存在 |

**幽灵演示测试**：只按顺序读各页行动标题，应能讲出完整论证。讲不通，先修标题/结构再制作。

**标题长度**：1–2 行为限；更长说明观点还不够锋利。
**标题字号**：24–28pt 加粗，后排可读。

---

## 3. 图表纪律

### 每页一个图表展品
一页一张图表/表格/图示/公式块/地图。需要两张图才能说明一个点，先判断：是同一个比较（可合并）还是两个不同观点（需要两页）。

### 每个展品必须证明自己的存在
展品必须直接支撑行动标题。测试：遮住展品读标题——没有它标题还成立吗？成立就不需要它。遮住标题看展品——结论显而易见吗？不明显就需要更强的标注或更清晰的行动标题。

### 在图上直接标注关键发现
不让听众自己找。用：
- 指向箭头或标签
- 高亮/阴影区域
- 文字批注框（"↑ 高于基线 23%"）
- 焦点系列用不同颜色

大教室屏幕远，这一点尤其重要。

### 自足幻灯片测试
不看讲解能否理解本页要点？不能就加标注。幻灯片常被当作 handout 或 PDF 传阅，必须脱离讲者也能传达信息。

### 图左文右
图放左侧，解读要点放右侧，符合从左到右的自然阅读顺序：先证据，后解读。

### 结果优先用图，少用表
表格在时间压力下认知负荷高。展示趋势、比较、分布用图；精确数值对比才用表。

### 重绘论文插图
不要从 PDF 直接复制论文图：分辨率低、字体小、图注不适用于屏幕。按演示分辨率重绘，坐标轴标签 ≥16pt。

### 不放入你不打算讲的展品
放进去就要讲；没时间讲就移入附录。

---

## 4. 文字纪律

### 正文每页 ≤ 约 40 字词
超过就：(a) 这页负担过重该拆分，或 (b) 内容属于附录/handout。

### 要点是提示，不是信息传输
每条要点一个意思，一页 3–5 条为典型，超过 5 条是警告信号。

### 电报式表达可以接受
省略冠词和填充语，保留含义：
- 原句："我们的研究发现干预显著降低了成本。"
- 改为："干预使成本降低 23%（p < 0.01）"

### 正文字号 ≥ 20pt（下限，不是目标）
塞不下就删内容，直到 20pt 放得下。

### 加粗/斜体克制使用
加粗：关键术语首次出现、行内标签（"注意：""局限："）、焦点发现。斜体：统计符号、物种名、书名。不作装饰。

---

## 5. 引用与署名

### 页内引用
非原创的每个论断、图表、数据集都必须在所在页标注来源，页底 12–14pt 灰色小字。格式按学科惯例（作者, 年份），全篇一致。

### 口头交代来源
引用出现前口头说明："张三等（2022）发现……"——不要默默闪现一个括号。

### 来自出版物的图表
- 图下方直接加来源图注（如"来源：李四等，2021，图3"）
- 参考文献页列完整条目
- 注意：复制已发表论文的图可能需要出版方许可；会议演示通常适用合理使用，不确定就查证。

### 参考文献页
正文前最后一页（附录前）必须是参考文献页，列出全篇所有引用来源的完整条目，格式与学科惯例一致。

---

## 6. 页面架构（完整学术演示的必需页面，按顺序）

### 标题页
- 完整演示标题（用陈述句或问句呈现，而非纯主题词）
- 作者与单位
- 会议/场所/活动名称
- 日期

### 动机/背景（1–2 页）
- 这个问题为什么重要？
- 对应文献中的真实缺口、未解问题或有后果的谜题
- 即 SCR 框架中的"情境"与"冲突"

### 研究问题/假设（1 页，独立成页）
- 明确、精确地陈述
- **这页必须存在**。不要把它并进动机页；给它独立一页，听众才能定位

### 方法（1–2 页）
- 只讲听众评估结论所需的部分
- 不影响可解释性的过程细节放附录
- 定量：识别策略、样本、关键变量；定性：数据来源、分析方法、证据标准

### 结果（按需多页，一页一个发现）
- 每页一个展品
- 行动标题陈述发现
- 关键结果在图表上直接标注

### 讨论/启示（1–2 页）
- 解释发现
- 回扣开篇研究问题
- 直接面对主要局限——抢先回答听众的质疑

### 结论（1 页）
- 2–4 条要点重述核心结论
- **这页在 Q&A 期间停留在屏幕上，是听众看到的最后一页**
- 后面不要接"谢谢"或空白页

### 联系方式/后续（结论页上或最后的独立页）
- 邮箱或主页地址
- 指向幻灯片/预印本/工作论文的二维码或短链
- 如适用："工作论文，欢迎反馈"

### 参考文献
- 全篇引用来源的完整条目

### 附录（明确标注）
- 预制的 Q&A 页（预判听众问题）
- 稳健性检验与敏感性分析
- 主叙事放不下的额外数据、图表、表格
- 详细推导或证明
- 每页明确标注（如"附录 A：稳健性检验"）

## 7. 时间与节奏控制

### 页数预算：每分钟至多 1 页
典型预算：
- 10 分钟报告：8–10 个内容页（不含标题与参考文献）
- 15 分钟报告：12–14 个内容页
- 20 分钟报告：15–18 个内容页
- 45 分钟研讨：30–40 页（每页讨论时间更长）

### 演练规则
出声计时演练，目标比规定时间**提前 1–2 分钟结束**。现场紧张和互动必然增加耗时。学术会议超时是严重的职业失误——议程严格按时间走。

### 知道该砍什么
提前确定时间不够时跳过的页，角落做小标记。优先保研究问题、关键结果、结论；方法与背景通常最先压缩。

### Q&A 准备
- 预判最可能的 3–5 个问题
- 为每个问题预建附录页
- 常见问题："为什么不用 X 方法？""与 Y 相比如何？""内生性怎么办？""样本有代表性吗？"

### 以结论页收尾
说"我就讲到这里"时，结论页应已在屏幕上。邀请提问："大家有什么问题或反馈？"（比"有问题吗？"更能引出实质性讨论。）

---

## 8. 国际化与无障碍

### 面向国际听众
- 避免习语、口语、文化特定的幽默
- 缩写首次出现即定义，即使是常见缩写
- 语速比感觉自然的慢
- 用平实、直接的句式

### 无障碍基础
- 正文 ≥20pt；标题 ≥24pt
- 文字与背景高对比（白底深字或深底白字）
- 不单靠颜色传达信息（同时用标签、图案、形状）
- 幻灯片作为 PDF 传播时给图加替代文本

## 9. 常见错误对照表

| 错误 | 修正 |
|------|------|
| 主题标签当标题 | 写行动标题（陈述结论的完整句子） |
| 呈现整篇论文 | 选一个论点，其余进附录 |
| 逐字念幻灯片 | 幻灯片承载证据，讲者承载论证 |
| 有证据无"so what" | 在图上直接标注关键发现 |
| 借用图表不标来源 | 页内引用；参考文献页列完整条目 |
| 正文 < 20pt | 删内容直到 20pt 放得下 |
| 格式不一致 | 一种字体、一种引用格式、统一网格对齐 |
| 放入不打算讲的页 | 没时间讲就移入附录 |
| 超时 | 限时内演练；知道该砍什么 |
| 以"谢谢"收尾 | 以结论页收尾，Q&A 期间停留在屏幕上 |
| 埋没研究问题 | 独立成页、第 2–3 页内明确提出 |
| 没有参考文献页 | 始终保留一页 |
