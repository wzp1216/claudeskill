# 提醒邮件模板与措辞规范

适用范围：子流程 C 通过通达 OA 内部邮件发送的工作提醒。
原则：正式公文体、简洁准确、有据可查、结尾留联系方式。

## 主题格式

`【工作提醒】<事项>（<截止日期或时间>）`

示例：
- `【工作提醒】报送2026年度绩效自查表（11月10日前）`
- `【工作提醒】11月9日14:00 教务工作例会（行政楼302）`

## 正文结构（四段式）

```
<称呼>：

<背景/依据>。根据<通知/会议名称>要求，现将有关事项提醒如下：

<事项与要求>：需要对方做什么、提交什么、什么格式。

截止时间：<时间>。
联系人：万志平（教务处）。

此致

万志平
教务处
2026年11月7日
```

## 各场景要点

| 场景 | 必含要素 |
|---|---|
| 材料报送提醒 | 依据（通知名称）、材料清单、格式要求、报送方式、截止时间 |
| 会议提醒 | 会议名称、时间、地点、需准备材料/需汇报内容 |
| 催办 | 原事项、已发时间、当前要求、截止时间；语气委婉 |
| 通用事项 | 事项说明、要求、截止、联系人 |

## 措辞规范

- 称呼：校内人员用"<姓名>老师："或"<职务>"（如"张主任："），不确定时用"XX老师："
- 语气：正式、尊重、不命令；催办用"请尽快""烦请"等委婉表达
- 依据可附来源链接（门户通知 URL）；**文件名和文号不凭记忆写**，以计划文件记录为准
- 正文不超过 150 字；无关信息不写

## 预览清单（发送前必须逐项展示给用户）

```
计划项 ID：T-20261107-01
事项：报送2026年度绩效自查表
收件人：李四（智能制造学院，OA账号：lisi）[共 1 人]
抄送：（无）
主题：【工作提醒】报送2026年度绩效自查表（11月10日前）
正文：<全文>
草稿路径：drafts/2026-11-07/T-20261107-01-李四.md
```

用户回复**针对该计划项的固定确认语**（如"确认发送 T-20261107-01"）后才可发送；
泛泛的"好/可以/行"不作为发送授权。

## 草稿文件格式

草稿落在 `drafts/YYYY-MM-DD/T-YYYYMMDD-NN-<收件人>-<slug>.md`：

```markdown
# 邮件草稿 T-20261107-01

- 计划项：T-20261107-01 报送2026年度绩效自查表
- 收件人：李四（智能制造学院）oa_user_id=lisi
- 抄送：
- 主题：【工作提醒】报送2026年度绩效自查表（11月10日前）
- 状态：待确认
- 创建：2026-11-07 08:30

---

<正文全文>
```

状态流转：`待确认` → 用户确认后改为 `已确认待发送` → 发送并核实后改为
`已发送 HH:MM`（或 `待核实` / `失败：原因`）。
