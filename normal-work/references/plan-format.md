# 计划文件格式规范

计划文件是 normal-work 的唯一持久化真相。所有门户通知、会议、OA 邮件摘要与
计划项都落在当日 Markdown 中，不另建数据库。

## 位置与命名

- 固定目录：`/media/data/AAAwork/claude/normal-work/plan/`
- 日文件：`YYYY-MM-DD.md`（与 cwd 无关，绝对路径）
- 周文件：`week-YYYY-MM-DD.md`（周一日期；任务总表，见文末"周工作文件"节）
- 历史文件**永不修改**；完成/取消只改当日（当周）文件

## 计划项 schema

- **ID**：`T-YYYYMMDD-NN`，创建日 + 当日序号；滚动时沿用原 ID
- **状态标记**：`[ ]` 待办、`[x]` 完成、`[-]` 取消；延期 = 改截止日期 + 备注说明
- **字段**（`  - 字段名：值`，按序排列）：
  - 必填：优先级（高/中/低，默认中）、OA提醒状态
  - 选填：截止、涉及人员、来源、来源ID、链接、备注
  - 滚动专属：来源日（首次出现的日期）、滚动次数（每滚一天 +1）、原计划日（最近一次所在日期，与来源日不同才写）
- **OA提醒状态机**：`无需` → `未生成` → `草稿已生成` → `待确认` → `已发送 YYYY-MM-DD HH:MM`；异常：`待核实`、`失败：原因`

## 滚动算法（plan_manager.py rollover）

1. 扫描 plan/ 下最近 `--lookback`（默认 7）个自然日的文件（不含当日）
2. 按文件日期从旧到新解析所有计划项，同一 ID 以最新文件的状态为准
3. 最新状态为 `[ ]` 且当日文件中无相同 ID / 规范化标题的项 → 复制进"三、昨日未完成（滚动）"
4. 滚动次数 +1；保留来源日；若最新所在日期 ≠ 来源日，补写原计划日
5. `[x]`/`[-]` 不滚动；重复运行幂等（ID 已在当日则跳过）

## 生成块（block）与手工内容的分界

- "一、门户信息"和"二、OA 邮件摘要"是**生成块**（`<!-- normal-work:portal/oa:start/end -->` 标记包裹），每次刷新整体替换；块内内容不要手工编辑
- "三、四、五、六"是**用户区域**：脚本只做单条增改和清单刷新，绝不整文件重写，保留手工编辑
- 同日重跑：只替换生成块 + 按来源ID 去重新增建议项；不重复滚动

## 脚本操作约定

- 所有增删改通过 `scripts/plan_manager.py` 完成（原子写入 + 文件锁）
- 门户/OA 提取结果先写到 `tmp/` 下的内容文件，再用 `replace-block` 替换，避免长参数
- 计划项建议由 Claude 判断后逐条 `add`，必须带 `--source` 与 `--source-id`；
  `add` 带 `--source-id` 时脚本**自动跳过文件内已存在的同来源 ID**（幂等）
- `add` 不带 `--reminder` 时默认写 `OA提醒：无需`
- 来源ID 规则：页面提供的 ID 优先（OA 邮件用 EMAIL_ID、我的工作用流水号、
  会议公告用 data-id、周报表用隐藏列 ID）；否则用"来源类型+规范化标题"的
  md5 前 12 位（如 `portal-` + hash），保证同日去重稳定
- 数据源状态行由 `set-status --portal <状态> --oa <状态>` 更新（未给的项保留原值）

## 周工作文件（任务总表）

周文件是"处理工作"的主表：汇总本周从 OA（邮件/公告/我的工作）与门户
（通知/会议）提炼的全部行动项，跟踪完成状态；未完成项在周一滚动（COPY）
到下周文件。日文件保持信息采集 + 当日计划 + 提醒的职责。

### 位置与命名

- 文件：`plan/week-<周一日期>.md`，周一至周日为一个周期
- `plan_manager.py` 命令加 `--week` 即操作周文件（`--date` 自动取所在周周一）：
  `init/rollover/add/update/list`；`replace-block/reminders/set-status/
  log-send` 仅日文件

- 计划项 ID 前缀 `W-`（创建所在周周一日期 + 序号），滚动沿用原 ID

### 周滚动算法（rollover --week）

1. 扫描 `plan/week-*.md`，取周一日期小于本周一且最近的一个（即上周文件）
2. 解析上周文件全部计划项，状态为 `[ ]` 且本周文件无相同 ID / 规范化标题
   → COPY 进"二、上周未完成（滚动）"
3. 滚动次数 +1、保留来源日、原计划日重算（同 rollover 共用逻辑）
4. 幂等；`[x]`/`[-]` 不滚动；无上周文件时输出"无上周文件"

### 每日流程与周文件的衔接

- 启动检查：确保本周周文件存在（`init --week`）；**周一首次运行**先
  `rollover --week` 把上周未完成 COPY 进本周
- 晨间简报（子流程 A）提炼的建议项：写入日文件"四、今日计划"的**同时**
  写入周文件对应分类（来源 ID 相同，双方各自去重）
- "刷新OA / 补读邮件"同样把新行动项写入周文件
- 完成/取消：在周文件里改状态；日文件里同源项也同步改（按来源 ID 定位）
